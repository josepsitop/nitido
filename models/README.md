# Modelos de IA

Aquí van tus modelos `.onnx` (Nítido los detecta solo; botón **Recargar**).

Tres formas de conseguirlos:

1. Botón **Descargar modelos…** en la app (lista de `catalog.json`, ONNX ya listos).
2. Botón **Importar .onnx…** para copiar uno que ya tengas.
3. Los `.pth` se convierten con el workflow de GitHub «Convertir modelos a ONNX».

Guía completa con enlaces, licencias y recomendaciones: **MODELOS.md**.
Puedes añadir tus propias entradas a `catalog.json` (campos: name, use, scale, license, url, page; opcional sha256).
